# Security policy

## Supported versions

sbxflow is currently pre-1.0. Security fixes are provided for the latest
released minor line. Older minor lines may not receive fixes; upgrade to the
latest release before reporting a problem that may already have been resolved.

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/jamessawle/sbxflow/security/advisories/new).
This keeps reports and any supporting material private while a fix is assessed.

Do not open a public issue, pull request, or discussion for an undisclosed
vulnerability. Include the affected version, impact, reproduction steps, and
any suggested mitigation when possible. The maintainer will acknowledge and
assess reports as availability permits, but this volunteer-maintained project
does not promise a fixed response or remediation time.

After a fix is available, the project may publish an advisory and credit the
reporter unless anonymity is requested.
